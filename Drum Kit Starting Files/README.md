# Drum Kit Web App

## Overview
An interactive web-based drum kit application built as part of **Dr. Angela Yu's Full-Stack Web Development Bootcamp** on Udemy. This project demonstrates practical **DOM Manipulation** techniques using vanilla JavaScript.

## Purpose
This project serves as a hands-on exercise for learning and mastering:
- **DOM Manipulation** - Selecting, modifying, and interacting with HTML elements
- **Event Handling** - Responding to user clicks and keyboard input
- **JavaScript Objects & Constructors** - Creating reusable components
- **CSS Styling & Animations** - Visual feedback for user interactions

## Features
- **Click-Based Sound Generation** - Click drum buttons to play different drum sounds
- **Keyboard Support** - Press W, A, S, D, J, K, L keys to trigger drum sounds
- **Visual Feedback** - Button animations when triggered
- **Multiple Drum Sounds** - 7 different drum sounds (toms, snare, crash, kick bass)
- **Responsive Design** - Clean, intuitive UI with styled buttons

## How to Use
1. Open `index.html` in your web browser
2. Click the drum buttons or press keyboard keys (W, A, S, D, J, K, L) to play sounds
3. Watch the button animations for visual feedback

### Controls:
| Key | Sound |
|-----|-------|
| W | Tom 1 |
| A | Tom 2 |
| S | Tom 3 |
| D | Tom 4 |
| J | Snare |
| K | Crash |
| L | Kick Bass |

## Technologies Used
- **HTML5** - Semantic markup structure
- **CSS3** - Styling and animations
- **JavaScript (ES5)** - DOM manipulation, event handling, and audio playback
- **Web Audio API** - Sound playback functionality
